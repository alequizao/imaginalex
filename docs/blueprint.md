# **App Name**: IMAGINALEX

## Core Features:

- Geração de Imagem: Gerar imagens baseadas em um prompt de texto usando um modelo de IA generativa. Garantir alta resolução e realismo nas imagens o mais próximo do real possível.
- Prompt Primário Persistente: Salvar um prompt primário para usar como base para as imagens. Editar e atualizar conforme desejado.
- Prompts de Detalhe Dinâmicos: Adicionar prompts de detalhes que são anexados ao prompt primário ao gerar imagens, para maior controle.
- Exibição de Imagem e Prompt: Exibir visualmente as imagens geradas com seus prompts correspondentes e oferecer uma maneira de salvar as imagens. Oferecer uma interface do usuário para mostrar os prompts salvos isoladamente.

## Style Guidelines:

- Cor primária: Um azul claro calmante (#64B5F6) que lembra céus abertos.
- Cor de fundo: Azul muito claro (#E3F2FD), criando uma sensação limpa e arejada.
- Cor de destaque: Um violeta vibrante (#9575CD) para destacar elementos interativos e indicar o envolvimento da IA.
- Fonte sans-serif limpa e moderna para facilitar a leitura.
- Ícones simples e delineados para representar diferentes funcionalidades, como salvar imagens e editar prompts.
- Um layout baseado em grade para mostrar imagens geradas e prompts associados de forma organizada.
- Animações de fade-in suaves para imagens recém-geradas e transições entre diferentes visualizações de prompt.
